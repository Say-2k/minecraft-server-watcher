Это небольшой проект, который подключается к вашему боту тг при запуске сервера и закрытии
и изменяет сообщение о статусе сервера.

Для запуска у меня в контейнере указан sh файл в котором запускается такая строка с 4мя аргументами

```sh
exec ./minecraft-server-watcher *botId* *chatId* *messageId* *sh-file-for-start*
```

Подробнее: 

exec - для того чтобы докер обращался именно к нашему приложению по PID 1

./minecraft-server-watcher - ссылка на скомпилированный файл

botId - идентификатор бота из BotFather

chatId - идентификатор чата в который он должен писать

messageId - идентификатор сообщения

sh-file-for-start - ссылка на sh файл который запускает майнкрафт (тоже должен иметь exec)


З.Ы. Идентификатор чата и сообщения можно взять просто скопировав ссылку сообщения
Например: https://t.me/c/3333333333/4444, 3333333333 - chatId, 4444 - messageId
